# SkillSwap — MVP (Flutter)

## Запуск
1. Установи Flutter.
2. В корне проекта:
   ```
   flutter pub get
   flutter run
   ```
   Приложение запускается в демо-режиме без подключения к Firebase. Регистрация и вход работают локально: данные не проверяются сервером и не сохраняются.

## Что внутри
- Локальный демо-поток регистрации / входа; после выхода открывается экран приветствия
- Создание карточек, избранное, запросы и чаты с отправкой сообщений работают локально
- Можно выбрать видеофайл на устройстве, добавить урок и воспроизвести его
- Демонстрационные данные хранятся только в памяти и сбрасываются после закрытия приложения
- Firebase и серверное хранение пока не используются
